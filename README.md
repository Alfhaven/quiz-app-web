## 📌 Sobre o projeto

O Quiz App é uma aplicação web onde o usuário responde perguntas sequenciais e recebe feedback imediato sobre acertos e erros, com pontuação exibida ao final. O projeto foi desenvolvido com foco em manipulação do DOM, lógica de controle de fluxo e estilização responsiva, sem depender de nenhuma biblioteca externa.

---

## ✨ Funcionalidades

- ❓ Perguntas sequenciais com múltipla escolha
- ✅ Feedback imediato de acerto ou erro
- 📊 Pontuação exibida ao final da partida
- 🔄 Opção de reiniciar o quiz
- 📱 Layout responsivo

## ⚙️ Como executar

Não há dependências — basta abrir o arquivo no navegador:

1. Clone o repositório
```bash
git clone https://github.com/Alfhaven/quiz-app-web.git
```

2. Abra `index.html` no navegador

Ou acesse diretamente pelo GitHub Pages (se habilitado).

---

## 💡 Conceitos aplicados

- Manipulação do DOM com `querySelector` e `addEventListener`
- Controle de estado com variáveis JavaScript
- Iteração sobre arrays de perguntas
- Feedback visual dinâmico com alteração de classes CSS
- Estrutura de dados com objetos para perguntas e respostas
